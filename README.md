# Drag & Drop Kanban Board

A simple Kanban board built to practice the **HTML Drag and Drop API** using HTML, CSS, and JavaScript.

## Features

* Drag and drop cards between different lists
* Visual indication when dragging over a list
* Simple and responsive layout
* Uses JavaScript Drag and Drop events

## Technologies Used

* HTML5
* CSS3
* JavaScript

## What I Practiced

* `draggable` attribute
* `dragstart` and `dragend`
* `dragover`
* `dragenter` and `dragleave`
* `drop`
* `dataTransfer`
* DOM manipulation
